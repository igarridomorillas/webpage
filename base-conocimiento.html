Programación

La programación en informática se usa para desarrollar programas que digan al ordenador cómo hacer tareas repetitivas, de precisión o complicadas para los humanos.

Lenguajes de programación

Un lenguaje de programación es la forma que le decimos al ordenador cómo tiene que realizar sus tareas. Existen numerosos lenguajes de programación. Muchos son de propósito general, se puede hacer cualquier tipo de programa con ellos. Otros son especializados para un area determinada. Para saber más sobre lenguajes de programación, pulsa aquí.

JAVA
JAVA es un lenguaje orientado a objetos de propósito general.
